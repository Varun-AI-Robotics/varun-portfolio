# Varun Kumar Portfolio

A responsive React + Vite portfolio with a dark futuristic UI.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Personalize before publishing

- Replace `your-email@example.com` in `src/components/Hero.jsx` and `src/components/Contact.jsx`.
- Update the LinkedIn URL in those same files.
- Verify each project repository URL in `src/data/projects.js`.
- Add your resume to `public/` and link it from the Hero section if desired.

The icon imports use standard `lucide-react` exports only. GitHub and LinkedIn are represented with generic code/profile icons to avoid unsupported brand-icon exports.
